<h1 align="center">Vira</h1>
<h2 align="center">Behavior control for AI systems</h2>
<p align="center">AI behavior is how a system responds, makes decisions, and takes actions. Simply put, it’s what your AI says, decides, and does.</p>

<p align="center"><strong>Under active development — product access is not open yet.</strong> <a href="https://studio.tryvira.xyz">Visit Vira Studio</a></p>

Vira does not guarantee that every model response is correct. It is being built to help teams review how their AI systems behave and improve those behaviors over time. [Teach AI](docs/teach.md) describes the public, customer-facing improvement journey.
