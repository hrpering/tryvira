# MCP example

Run the published Vira MCP launcher:

```bash
npx -y @tryvira/mcp
```

After initialization call `tools/list`. Start with read-only tools such as `resolve_semantic`, `list_ai_systems`, `list_behavior_programs`, `list_behavior_strategies`, `list_discovery_candidates`, and `list_packs`.

The current package also exposes advanced Strategy execution and behavior projection tools. Effectful tools remain authority-gated.

See [MCP reference](../../docs/reference/mcp.md), [MCP 31-tool catalog](../../docs/reference/mcp-tools.md), and [Capability map](../../docs/capability-map.md).
