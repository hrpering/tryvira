# Customer example: Coordinate one complete governed behavior improvement

## Scenario

Use the Marketing Agent tutorial for the customer journey, then return through permitted evidence, Teach proposal review, candidate evaluation, separately authorized promotion/release, runtime verification, and the next evidence cycle.

## Run and verify

This is a multi-command customer tutorial, not one atomic automation. Follow its non-production and separate authority gates; live tenant execution is not claimed.

This example uses the customer’s own configured Vira deployment when it is executable. It does not include a mock Vira server, shared credentials, customer records, or private production data. Where the public contract or account capability is not available, the example is a review procedure and explicitly says where execution must stop.
