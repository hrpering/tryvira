# Release a governed revision safely

## Short test prompt

> Release the evaluated support Pack in the approved sandbox and verify the live identity.

## Detailed test prompt

> Read exact eligible immutable revision, approval, digest, scope and prior release. Perform only documented mutation after authorization; check persisted release and subsequent AUTO selection.

## Expected result

Report real before/after identity, rollback target, child status, missing provider-verifier evidence.

Follow the [production-aligned Skill](https://github.com/hrpering/tryvira/blob/main/skills/vira-release/SKILL.md) and [canonical TaskRun](https://github.com/hrpering/tryvira/blob/main/docs/canonical-taskrun.md). Live execution requires customer-authorized non-production scope, real server IDs and supported installed client operations. Never fabricate an acceptance receipt.

## Negative test

No generic rollback() guess; deleting active behavior is not rollback; completion is not post-model PASS.
