# Customer example: Install a published client and configure its host

## Scenario

Install the current client from the registry, verify the installed version, and initialize the MCP host before using any tool.

## Reference

- Workflow guide: [published-packages.md](https://github.com/hrpering/tryvira/blob/main/docs/published-packages.md)
- Customer artifact or runnable code: [README.md](https://github.com/hrpering/tryvira/blob/main/examples/frameworks/mcp-client/README.md)

## Run and verify

Run the MCP client example only after configuring the customer endpoint and server-side credentials; call tools/list before selecting a tool.

This example uses the customer’s own configured Vira deployment when it is executable. It does not include a mock Vira server, shared credentials, customer records, or private production data. Where the public contract or account capability is not available, the example is a review procedure and explicitly says where execution must stop.
