# Customer example: Add a governed boundary to an existing agent framework

## Scenario

Use the framework’s normal model invocation path, resolve Vira runtime first when enabled, and preserve the framework’s native message/result types.

## Run and verify

Run the framework example that matches the project; the examples call configured services and do not include a mock Vira server.

This example uses the customer’s own configured Vira deployment when it is executable. It does not include a mock Vira server, shared credentials, customer records, or private production data. Where the public contract or account capability is not available, the example is a review procedure and explicitly says where execution must stop.
