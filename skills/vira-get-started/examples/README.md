# Customer example: Choose a customer integration path

## Scenario

Review the customer deployment requirements, select the JavaScript, Python, or MCP surface that the account actually exposes, then start the matching example.

## Reference

- Workflow guide: [quickstart.md](https://github.com/hrpering/tryvira/blob/main/docs/quickstart.md)
- Customer artifact or runnable code: [README.md](https://github.com/hrpering/tryvira/blob/main/examples/frameworks/README.md)

## Run and verify

Use the framework directory that matches your application. Start with a read-only or OFF-mode request, then connect only after the customer supplies scoped credentials.

This example uses the customer’s own configured Vira deployment when it is executable. It does not include a mock Vira server, shared credentials, customer records, or private production data. Where the public contract or account capability is not available, the example is a review procedure and explicitly says where execution must stop.
