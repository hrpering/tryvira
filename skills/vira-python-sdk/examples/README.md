# Customer example: Connect a Python assistant and observe one turn

## Scenario

Install the published Python client, connect the existing system, and submit a minimized synthetic observation.

## Reference

- Workflow guide: [README.md](https://github.com/hrpering/tryvira/blob/main/examples/python/README.md)
- Customer artifact or runnable code: [connect_observe.py](https://github.com/hrpering/tryvira/blob/main/examples/python/connect_observe.py)

## Run and verify

Install the documented package version in a virtual environment, configure the customer endpoint and scope, then run connect_observe.py.

This example uses the customer’s own configured Vira deployment when it is executable. It does not include a mock Vira server, shared credentials, customer records, or private production data. Where the public contract or account capability is not available, the example is a review procedure and explicitly says where execution must stop.
