# Vira public developer repository

This repository contains public documentation, client examples, and Agent Skills.
Use published package artifacts and the public contract documentation as the
authority for integration guidance.

## Production source boundary

The production repository is reference-only for this project. Do not edit it,
run its applications or test commands, access its services, use its credentials,
or perform production mutations. If a source detail is not reflected in a
published package or public API contract, do not copy that detail into this
public repository. Record an unresolved contract as a limitation instead.

Do not publish, push, or release this repository unless the user explicitly
authorizes that action. Keep all examples synthetic and all credentials as
environment-variable placeholders.
