# Support

Use GitHub Issues for reproducible problems with:

- public documentation and examples;
- `@tryvira/sdk`;
- `tryvira-sdk`;
- `@tryvira/mcp`.

Include the package/docs version, operation, public error code/status, and request ID when available.

Do not post account data, billing information, credentials, personal data, customer data, or confidential deployment details in public issues.
