# Published SDK method inventory

This method map was checked against published `@tryvira/sdk@0.1.43` and `tryvira-sdk==0.1.43` on 2026-11-07. JavaScript names come from the package's `ViraClient` declarations; Python names come from callable public methods on the installed `ViraClient`. Methods are grouped by the skill that should guide their use. A method's presence in an SDK does not prove that the current credential, deployment, or role can use it.

`npm run verify:registry` downloads the latest artifacts and compares their complete public method sets with this map. If a package adds or removes methods, that check fails until this map and the related skill/API references are reviewed. It deliberately does not invent a skill mapping for a new method.
