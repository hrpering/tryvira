# Live Agent Skill Acceptance (read-only)

This is an acceptance procedure for a **real authorized, isolated, non-production tenant**. The source level unit tests can run without accounts; this procedure cannot.

## Required setup

Install the versioned published \`@tryvira/sdk\` in \`examples/javascript\` and configure \`VIRA_API_URL\` (actual deployment root, no \`/v1\`) and \`VIRA_API_KEY\` securely in the process environment.

Collect these IDs from a real server/Studio record, not from fixture strings:
- The organization/project/environment, AI System and Connection
- One **ACTIVE + APPROVED** Signal producer mapping with a real mapping digest
- One **RELEASED** Pack with its immutable digest
- One actual completed evaluation ID plus its server status
- One real Teach analysis ID/status
- Four actual TaskRun IDs, **SINGLE/STRATEGY/COMPOUND/HYBRID**, each generated by AUTO, with exact input digests

Create a **local, gitignored** manifest with this shape, replacing every \`REPLACE_\` value using real readbacks:

~~~json
{
  "organizationId": "REPLACE_ORG",
  "projectId": "REPLACE_PROJECT",
  "environmentId": "REPLACE_ENV",
  "aiSystemId": "REPLACE_AI_SYSTEM",
  "connectionId": "REPLACE_CONNECTION",
  "packId": "REPLACE_RELEASED_PACK",
  "evaluationId": "REPLACE_EVAL",
  "expectedEvaluationStatus": "REPLACE_REAL_STATUS",
  "signalMappingId": "REPLACE_APPROVED_MAPPING",
  "teachAnalysisId": "REPLACE_TEACH_ANALYSIS",
  "expectedTeachStatus": "REPLACE_REAL_STATUS",
  "taskRuns": [
    {"expectedMode": "SINGLE", "taskRunId": "REPLACE_SINGLE", "expectedInputDigest": "REPLACE_INPUT_DIGEST"},
    {"expectedMode": "STRATEGY", "taskRunId": "REPLACE_STRATEGY", "expectedInputDigest": "REPLACE_INPUT_DIGEST"},
    {"expectedMode": "COMPOUND", "taskRunId": "REPLACE_COMPOUND", "expectedInputDigest": "REPLACE_INPUT_DIGEST"},
    {"expectedMode": "HYBRID", "taskRunId": "REPLACE_HYBRID", "expectedInputDigest": "REPLACE_INPUT_DIGEST"}
  ]
}
~~~

Command from an app folder where \`@tryvira/sdk\` resolves:

~~~bash
VIRA_API_URL=https://customer-api.example VIRA_API_KEY=... \
node skill-e2e-acceptance.mjs --manifest /path/to/untracked-real-ids.json
~~~

**Important:** The script is read-only. It does not install a Pack, approve/release, begin TaskRuns or synthesize a provider answer. It reads actual persisted entities and intentionally fails at the missing final verified provider-output receipt, even if all four TaskRuns are COMPLETED. This is an **honest red gate** until the production server publishes that readback contract.

## Failure matrix

| Case | Required result |
| --- | --- |
| Missing scope, wrong tenant | Deny before reading another tenant's resources |
| Signal mapping PROPOSED/REVOKED | Not approved runtime authority |
| Pack evaluated but not RELEASED | No runtime eligibility claim |
| Eval ID stale/unbound to Pack digest | No evaluation pass claim |
| Teach analysis QUEUED | Not a completed behavior change |
| STRATEGY plan unavailable | No fabricated Strategy child |
| COMPOUND/HYBRID partial | No overall success |
| Provider output present, post-model verification missing | Not verified |
| Verifier PASS for a different output digest | Not verified |
| Child COMPLETED without final provider evidence | Not verified |

For the host-side final-answer integration requirements, see [Verified answer handoff](../verified-answer-handoff.md) and [Runtime verification](../runtime-verification.md). This script is **not** an API implementation or a shortcut around missing backend capabilities.

## Real model Skill selection

~~~bash
python3 scripts/eval_skill_selection.py --validate-only
python3 scripts/eval_skill_selection.py --command '/path/to/real-agent-trace-adapter' \
  --out /tmp/vira-actual-model-selection.jsonl
~~~

The adapter reads one JSON request on stdin and responds on stdout with:
\`caseId\`, actual \`agent\`, actual \`model\`, \`traceId\`, \`selectedSkills\`, \`source:"live_agent_trace"\`, \`simulated:false\`. The adapter must collect selected Skill loads from **agent telemetry**, not ask the LLM to guess which Skill it used. The scorer refuses incomplete/missing traces and never claims automatic-selection accuracy based on the synthetic prompt corpus alone.
