# Strategy integration checklist

Before using a Behavior Strategy:

- confirm that the installed SDK version supports the methods you need;
- consult the published SDK or HTTP API reference for exact fields and response types;
- keep examples synthetic and avoid embedding credentials or customer data;
- validate and evaluate a candidate before taking any separately authorized action;
- check MCP's current tool catalog instead of assuming feature parity with the SDK;
- verify the resulting behavior in the environment where it will be used.

This checklist describes integration hygiene only. It does not replace the package
contract or grant account permissions.
