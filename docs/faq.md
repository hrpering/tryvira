# FAQ

## Is Vira a prompt manager?

No. Prompts may be one component, but Vira covers behavior lifecycle, semantic resolution, evaluation, release, runtime, and traceability.

## Is Vira an observability tool?

Not only. Observation is one input into the behavior lifecycle.

## Does Vira automatically learn from every conversation?

No. Evidence can support a proposal. A proposal is not automatically production behavior.

## Can semantic routing be uncertain?

Yes. Uncertainty and no-match are valid outcomes.

## Do Strategies override policy?

No. Strategy describes bounded execution. Hard policy authority remains separate.

## Are raw receipts public?

No. This public repo intentionally uses simple traces and does not document internal receipt structures.

## Is the private Vira server open source?

Not through this repository. This repository contains public documentation, examples, and public integration guidance.
