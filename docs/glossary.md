# Glossary

## AI System

A connected agent, application, copilot, or model-backed system.

## Semantic Task

A governed task definition used by semantic resolution.

## Behavior Point

A stable attachment point for governed behavior.

## Signal

Typed evidence consumed by behavior or discovery.

## Behavior Program

Structured behavior modules attached to governed context.

## Strategy

A bounded execution graph associated with a Behavior Point.

## Teach

Evidence-to-proposal lifecycle.

## Evaluation

A test of a candidate change.

## Approval

An explicit decision to allow a candidate to move toward release.

## Release

Approved behavior eligible for runtime.

## Runtime resolution

Resolution of released behavior for a request.

## Trace

A compact developer-facing explanation of what was selected and applied.
