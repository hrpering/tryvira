# Contributing

This repository accepts improvements to public documentation, examples, and supported integration guidance.

## Good contributions

- documentation fixes;
- public SDK examples;
- MCP examples;
- public API corrections;
- accessibility improvements;
- reproducible issues against published public packages.

## Do not submit

- private Vira server source;
- internal prompts;
- proprietary thresholds;
- raw internal receipts;
- customer data;
- production credentials;
- private infrastructure details.

## Verify

```bash
npm ci
npm run verify
```

## Pull requests

Keep one clear purpose per pull request.

Use fictional data.

Update documentation when a public contract changes.
